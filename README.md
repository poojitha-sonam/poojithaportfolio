# Poojitha Sonam — Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript. No installation, build step, external fonts, or paid services are required.

## Files

- `index.html` — complete website, including styles and interactions.
- `assets/southwest-fuel-attendee-list.xlsx` — original supplied workbook, unchanged.
- `.nojekyll` — serves the website without Jekyll processing on GitHub Pages.

## Upload to GitHub

1. Extract this ZIP on your computer.
2. Create a new GitHub repository, for example `poojitha-portfolio`.
3. Open the repository and choose **Add file → Upload files**.
4. Upload the contents of the extracted `poojitha-portfolio` folder. Put `index.html` at the repository root, and keep the spreadsheet inside the `assets` folder. Do not upload just the ZIP or put the whole project inside another parent folder.
5. Commit the uploaded files to the `main` branch.
6. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
7. Once deployment finishes, GitHub Pages will display your website address. A project repository typically uses `https://YOUR-USERNAME.github.io/poojitha-portfolio/`.

## Customize

Open `index.html` in any text editor to update contact information, work experience, dates, and content. The color palette is defined in the CSS `:root` section. The Excel link is relative, so it works on a GitHub project site as well as locally.

Open `index.html` directly in your browser to preview. The portfolio includes responsive mobile navigation, email/phone/LinkedIn links, the workbook download, and a print / save-as-PDF button.

## Work sample details

The original workbook has two worksheets. The website counts 267 populated contact rows in the first worksheet: 210 Fuel Retail, 47 Fuel Distributor/Wholesaler, 7 QSR, and 3 General Retailer. These are counts of records, not verified unique people. The site presents the workbook as a supplied work sample and does not assert its authorship or independently verify its contact data. The workbook itself is not modified.

## Before public publication

The supplied spreadsheet includes other people's email addresses and phone numbers. Upload it to a public repository or public website only if you have permission to share that data. If needed, replace it with an anonymized sample at the same filename before uploading. Removing the download button alone does not make the uploaded workbook private. Personal phone and email information from the supplied résumé also appear on the portfolio.

The experience dates and immediate-joiner availability follow the supplied résumé; update them if they change.
